# Ink Sky

Land anywhere. Name what you find. Get trophies. A sister game to Ink Nine, Ink Rally and Ink of Arms.

- `index.html` is the front page; the game is in `play/`.
- The universe (planets, weather, creatures, upgrades) is made in `play/js/gen.js`.
- `CLAUDE.md` explains the project to Claude Code, and `CHANGELOG.md` lists what changed in each version.

To run it on your computer: open a terminal in this folder, run `python -m http.server 8020`, then visit http://localhost:8020
